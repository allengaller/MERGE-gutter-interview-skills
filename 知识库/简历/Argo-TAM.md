## 开源项目（22 个 · 覆盖 Agent 工程 / AI Infra / 云原生运维 / 知识工程）

> 详细版（每个项目的定位 / 技术亮点 / 硬指标 / 对比 + 数字速览）见 [开源作品集.md](开源作品集.md)。

### Agent 工程

- **resolve-agent**：基于 AgentScope 的生产级产品支持智能体平台——以 Loop 工程思路把从告警、根因定位到修复执行的响应链路端到端自动化；接收客户多模态输入后，按故障特征在 FTA 故障树、WIKI 知识库、技能与代码分析之间智能路由，把诊断与处置闭环收敛在同一平台；已实现 432 个场景、23 项 Agent 定制功能，支持 WebUI 与 Mac App（在研）
- **agent-up**：Agent 配置全生命周期管理平台——覆盖编辑、审批发布、效果追踪到一键回滚的完整闭环；用户反馈经 AI 归因自动转化为配置变更建议，上线后自动生成效果报告，四分区编辑器支持分区级回滚，变更全程可审计可撤销；232 个自动化测试、30 个 API
- **docsy**：面向 Agent 时代的文档平台——把普通 Markdown 重构为机器可解析、可校验、可执行的研究包；内置 14 条 Linter 规则与 0-100 健康评分，实测稳定支撑 21,000 篇文档大仓库，文档可被 AI 直接消费与验证；175 个自动化测试、覆盖率 81%
- **mcp-database**：自托管 MCP Server 统一框架（mcp4coder）——37 个 Server、200+ 工具收敛进统一基类，新增一个 Server 只需实现两个方法，接入边际成本从周级降到小时级；内置 JWT 双认证与沙箱隔离
- **sokr**：运维团队 OKR 与复盘沉淀工具——目标、关键结果、专项、课题、工单、技能六层链路，把故障复盘转化为可毕业的团队技能资产；纯浏览器零部署，330 个自动化测试
- **skills-database**：职业技能与 Skills 技能融合平台——455 条面向岗位胜任力的技能、27 个职业角色，每条来源可溯、分类可幂等重建，单文件离线浏览

### AI Infra 与云原生

- **kudig-database**：K8s 与 AI Infra 生产运维全域知识库——4,750 篇文档、21 个技术域、13 家云厂商；故障树引擎沉淀 16 个顶层事件、约 300 个底事件；按人与 AI Agent 双读设计，可直接作为 LLM-Wiki 语料接入智能体
- **ai-guru-database**：中文 AI 全栈开源知识库——2,061 篇核心文档约 1,894 万字、700+ 概念卡，从数学基础一路讲到 Agent 生产部署；24 章完整体系 + 三层阅读路径
- **klaw**：单二进制 K8s 智能运维平台——一个文件同时提供控制台、诊断引擎、ChatOps 机器人、实时告警与 SOS 语音五种能力；9 大类 73 个分析器，事件推送延迟低于 1 秒，排障 API 调用下降约 90%
- **etcd-guardian**：etcd 备份恢复 Kubernetes Operator——直调 etcd 原生快照与恢复接口，保证 revision 一致性与成员重建顺序，补上 Velero 在托管集群摸不到 etcd 数据面的盲区；支持 10GB+ 大库，对阿里云 ACK 用户开箱即用
- **kubernetes-network-master**：K8s 网络排障 kubectl 插件——从 DNS、网络策略、Service 逐跳因果链追踪到 TCP、MTU、CNI 并自动标记断点，20+ 子命令，内含 CNI 无关的轻量 eBPF；断点定位收敛为一条命令

### TAM / SRE 领域

- **open-tam**：基于 AgentScope 与 MCP 的多 Agent 排障系统——告警进来，输出带现象、根因、处置建议的三段式报告；排查即语料，每一步思考、工具调用与观察落盘为可回放 trace，故障注册表即评测集，仿真 mock 与实盘切换零改动
- **kuba-database**：全网重大生产故障复盘数据库——94 个 P0-1 级真实案例、46 年跨度、47 家公司、12 类根因，按 SRE、CRE、FDE 等多角色视角结构化拆解，全库纯 Markdown + 版本管理
- **cmd-database**：命令行语料数据库——1,100+ 命令各建一页、741 篇生产最佳实践，YAML 单一来源生成双向链接文档，Go CLI 检索校验；既能当个人知识库，也直接作为 Agent 语料

### 交付工程与跨学科知识工程

- **fde-scope**：FDE 现场操作系统——资格预审、现场交付、运维化到客户交接全流程固化为 4 阶段、18 环节、10 道代码级门禁（7 道源自 FAT、ISO 13849、CE 等工业标准），把交接后的运维化纳入闭环

- **mechanic-romance**：具身智能研究语料库——把论文、代码、笔记三座孤岛统一到同一套场景模板与引用规范，10 篇方法笔记、22 种硬件、6 个仿真环境、8 个演示场景；待核实状态明示标注作为可信度门禁
