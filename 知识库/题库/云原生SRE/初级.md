## 概念题（口述，必走）

### 1. 解释 K8s 的 Pod 是什么
**及格线**：
- 一个 Pod = 一组共享网络 / 存储的容器
- Pod 里的容器共享 network namespace（同一个 IP）
- Pod 是 K8s 调度的最小单位

**追问**：
- Pod 跟容器的区别？
- 一个 Pod 通常装几个容器？

### 2. 解释 Deployment / ReplicaSet / Pod 的关系
**及格线**：
- Deployment 管 ReplicaSet（spec 版本）
- ReplicaSet 管 Pod 副本数
- Pod 是实际跑业务的

**追问**：Deployment 改 image，Pod 怎么重建？

### 3. 解释 Service 是什么 / 为什么需要 Service
**及格线**：
- Service 给一组 Pod 固定的访问入口
- 通过 label selector 找到 Pod
- 提供负载均衡 + 服务发现

**追问**：ClusterIP / NodePort / LoadBalancer 区别？

### 4. 解释 ConfigMap 和 Secret
**及格线**：
- 存非敏感配置用 ConfigMap
- 存敏感配置用 Secret
- 通过 volume 或 env 注入 Pod

**追问**：Secret 怎么加密？etcd 里是明文吗？

### 5. 解释 K8s 的三种 probe
**及格线**：
- LivenessProbe：容器不健康时重启
- ReadinessProbe：流量没准备好时不接流量
- StartupProbe：慢启动时屏蔽 liveness

### 6. 解释 kubectl get / describe / logs / exec 各自用途
**及格线**：
- get：列资源
- describe：详细事件
- logs：容器日志
- exec：进容器

### 7. 解释 namespace 是干嘛的
**及格线**：资源隔离 + 权限边界 + 配额管理

## 排查题（动手）

### 8. 一个 pod 一直 CrashLoopBackOff，怎么排查？
**考察点**：
- `kubectl get pods`：看状态
- `kubectl describe pod`：看 events
- `kubectl logs --previous`：看上次启动日志
- 常见原因：image 错 / 配置错 / 资源不够 / 健康检查失败

**及格线**：能按顺序说出这 3 个命令。

### 9. 一个 Service 后面的 pod 都不通，怎么排查？
**考察点**：
- `kubectl get endpoints` → 看 selector 有没有匹配到 pod
- `kubectl describe svc` → 看 label
- `kubectl exec` 进容器 curl 自己
- NetworkPolicy 是否拦截

### 10. 一个 Node 状态 NotReady，怎么排查？
**考察点**：
- `kubectl describe node` → 看 conditions
- 常见原因：kubelet 挂 / 网络问题 / 磁盘满 / 内存压力
- 进节点看 `journalctl -u kubelet`

## 知识题

### 13. K8s 的主要组件有哪些？
**及格线**（10 个能说 8 个算及格）：
- apiserver / scheduler / controller-manager / kubelet / kube-proxy
- etcd / CoreDNS / Dashboard / metrics-server / ingress-controller

### 14. Docker 和 ContainerD 什么关系？
**及格线**：
- Docker 是完整的容器平台（含 CLI、build、runtime）
- ContainerD 是 dockerd 拆出来的 runtime
- K8s 现在用 ContainerD 作为默认 runtime

### 15. 解释 K8s 的滚动升级流程
**及格线**：
- Deployment 改 spec.template
- ReplicaSet 起新 pod
- 慢慢替换旧 pod
- `maxSurge` / `maxUnavailable` 控制节奏

**追问**：怎么回滚？`kubectl rollout undo`
