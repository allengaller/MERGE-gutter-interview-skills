# Flow · 行为面试

> 适用岗位：所有岗位的最后一轮 / HR 面。**对资深岗不考，但对 P6+ 必考**。

## 总时长

30 分钟。**3-4 个 STAR 问题**。

## 阶段

### 1. 暖场（3 分钟）
- "聊聊你自己 — 3 分钟，讲讲你的职业轨迹"
- 听完后心里记下：转行 / 跨栈 / 关键转折点

### 2. STAR 提问（每题 5-7 分钟）

按主题抽 3-4 题（从 `../../../../知识库/题库/<角色>/行为面.md` 抽），主题覆盖：

- **冲突**：跨团队 / 上下游 / 上下级
- **失败**：项目失败 / 决策失误 / 个人短板
- **影响力**：技术影响业务 / 推动改变 / 带人
- **判断**：技术选型分歧 / 取舍 / 妥协

每个问题严格按 **STAR 追问**：

| 层级 | 问什么 | 为什么问 |
|------|--------|----------|
| **S**ituation | "当时是什么背景？为什么会出现这个事？" | 听大局观 |
| **T**ask | "你的角色是什么？目标是什么？" | 听个人贡献度 |
| **A**ction | "你具体做了什么？**不是**团队" | 听"我"不是"我们" |
| **R**esult | "量化结果？业务影响？团队影响？对你自己影响？" | 听反思能力 |

**关键追问**：
- "你做了什么 vs 别人做了什么？" — 防止把团队成绩揽自己身上
- "如果有第二次，你会怎么做不一样？" — 测反思
- "事后有没有落到 SOP / 文档？" — 测闭环

### 3. 反向提问（5 分钟）
- 必答用户的问题：**"你为什么想离开 / 想加入我们？"** 之类的，给个说法但不要教用户怎么答
- 听用户问了什么 → 反映他对这份工作的真实兴趣

### 4. 收尾
按 `../SKILL.md` 的"收尾模板"出反馈。

## 评分维度

见 `../评分/行为面.md`。

## 注意事项

- ❌ **不要**问假设性问题（"如果你遇到 XX 你会怎么办"）— 不准
- ❌ **不要**问"你最大的优点/缺点" — 烂大街，且不准
- ✅ 追问时**温和但坚定** — 行为面试容易让用户紧张
- ✅ 用户答得空 → "你说'协调了一下'，具体是怎么协调的？"
- ✅ 用户答得实 → 记下来，可以给亮点
