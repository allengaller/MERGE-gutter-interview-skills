## 设计原则

1. **SKILL.md 是入口，但 description 是触发器**。description 字段会被宿主 agent 读用来判断何时加载本 skill，所以**触发关键词要全**。

2. **角色卡 = 面试官剧本**。`角色卡/<角色>.md` 告诉 agent"你现在是谁""你考察什么""你的红线是什么"。**不要把用户背景也写这里** — 用户背景在 `知识库/画像/<角色>/` 里。

3. **流程文件 = 推进剧本**。`流程/<流程>.md` 写阶段、推进规则、信号识别（用户什么时候卡住、什么时候要追问）。不要在流程里写具体题。

4. **题库 = 弹药**。`知识库/题库/<角色>/` 才是真题目。Skill 入口**不存题**，避免双份维护。

5. **rubric = 评分卡**。`评分/<流程>.md` 是结构化评分维度；收尾时按这个打分。

## 新增角色 / 新增流程

### 新增角色
1. 复制 `角色卡/_模板.md` → `角色卡/<新角色>.md`，填字段
2. 在 `知识库/画像/<新角色>/` 建 `画像.md`、`项目.md`、`技能.md`
3. 在 `知识库/题库/<新角色>/` 建 `初级.md`、`中级.md`、`高级.md`
4. 在 SKILL.md 的"文件索引"表里加一行

### 新增流程
1. 在 `流程/<新流程>.md` 写阶段和规则
2. 在 `评分/<新流程>.md` 写评分维度
3. 如果是某角色特有的，在该角色的"默认流程"里指过来
4. 在 SKILL.md 的"文件索引"表里加一行

## 与知识库的边界

| 维度 | 在 skill 里 | 在知识库里 |
|------|------------|----------------|
| 面试官怎么演 | ✅ 角色卡/ | ❌ |

| 怎么打分 | ✅ 评分/ | ❌ |
| 题库（具体题） | ❌ | ✅ 题库/ |
| 主题知识 | ❌ | ✅ 主题/ |
| 用户背景 | ❌ | ✅ 画像/<角色>/ |
